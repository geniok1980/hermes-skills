# OCR-формат: разряженные цифры (spaced characters)

Реальные чеки из R-Keeper часто приходят в виде OCR-распознанного текста, где каждая цифра отделена пробелом.

## Пример

```
Омлет с лососем
1
.
7
9
2
,
0
0
.
1
шт
7
9
2
,
0
0
```

Это означает: цена 792,00, кол-во 1 шт, сумма 792,00.

## Алгоритм парсинга

1. **Собрать цифры в числа**: убрать все пробелы между цифрами, оставив запятые и точки как разделители.
2. **Идентифицировать поля по позиции**: после названия товара идёт номер позиции, затем цена, затем количество с единицей измерения, затем сумма.
3. **Формат строки**: `номер . цена . количество единица_измерения сумма`

## Правила восстановления

| Исходный фрагмент | Восстановленное значение |
|---|---|
| `9 6 0 8 , 0 0` | `9608,00` |
| `6 4 0 0 , 0 0` | `6400,00` |
| `0 , 0 5 л` | `0,05 л` |
| `3 1 . 0 5 . 2 0 2 6` | `31.05.2026` |
| `ИНН 9 7 0 7 0 4 1 6 2 5` | `ИНН 9707041625` |

## Особенности

- Запятая (`,`) — десятичный разделитель (русский формат)
- Точка (`.`) — разделитель между ценой, количеством и суммой в строке товара, а также разделитель в датах
- Единица измерения (`шт`, `л`, `кг`) идёт сразу после числа без пробела или с пробелом (`0,05л` или `0,05 л`)
- Номер позиции может быть на отдельной строке или слитно с ценой
- При `3 2 0 0 0` без запятой — считать `320,00` (запятая потеряна при OCR)
- При `9 6 4 0 0 0 0` — это номер `9`, затем цена `6400,00`
- Маркеры `АТНМ`/`Товар` с подписями `Полный расчет`/`Без НДС` — атрибуты предыдущей позиции, не отдельные товары
